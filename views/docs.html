Endpoints

Send a GET request to /api/<endpoint> with the listed query parameters, or a POST request to the same URL with a JSON body.

For POST, use avatars and usernames arrays in the listed order. Send all other parameter values as strings. For example: {"avatars": ["https://example.com/avatar.png"], "usernames": ["name"], "text": "hello"}.

Endpoints with multiple text fields require text1, text2, and so on. Each field accepts commas.

Authorization

Every API request requires a valid key in the Authorization header. Request a key on the dashboard.

Authorization: your-api-key

Image input

Image parameters must be HTTP or HTTPS URLs that the service can fetch. GET accepts image as an alias for avatar1. POST accepts images as an alias for avatars.

JPEG, PNG, and BMP are supported. Other formats may work if the installed Pillow build can decode them. Animated inputs use the first frame.

The image response must include a Content-Length header and cannot exceed {{ max_file_size }} bytes.

Rate limits

Each endpoint has the rate limit shown above. The global limit is 300 requests per 60 seconds. Requests that fail after authorization count toward these limits.

Responses include X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset for the endpoint, plus the corresponding X-Global-RateLimit-* headers for the global limit. Reset timestamps and Retry-After values are in milliseconds.

A rate-limited request returns HTTP 429. Global rate-limit responses include "global": true.
